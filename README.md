# 毎週アプリ（公開分）

株式会社タイガーラボが公開している、無料で使える小さなアプリ。
すべて単一のHTMLファイルで、外部への通信はありません（入力内容は端末の中だけで処理されます）。

| アプリ | 中身 |
|---|---|
| `hanashikata-fingerprint/` | AI回答しっくり診断 — 文章から話し方のクセを22の動物タイプに診断 |
| `ai-shijibun-maker/` | AIしっくり設定 — ChatGPT/Gemini/Claudeのカスタム指示欄に貼る設定文を生成 |

## 公開の仕組み

GitHub Pages（main / root）。`.gitignore` は「既定はすべて除外、許可したものだけ公開」方式。
新しいアプリを `apps/` に足しても、`.gitignore` に明示しない限り公開されません。
